# Word Analyzer

## Project Description
Word Analyzer is a Java application designed to analyze text and display useful information about the given input.

## Features
- Text analysis
- Word and character counting (if supported by the code)
- String manipulation
- Basic text processing

## Technologies Used
- Java
- Core Java
- String handling

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code or another Java IDE.
3. Compile and run the main Java class.
4. Provide text input to analyze.

## Purpose
Developed as part of a Java programming internship to practise Core Java concepts and text processing.
